# 已有方法的适配

各方法使用 A1+B1 训练、C1 验证、D1 测试，评价固定 HEG200 和 HEG50。基因选择、表达单位及指标见[基准协议](BENCHMARK.md)。下表列出本项目实际使用的实现。

| 方法 | 输入与预测方式 | 训练及选择 |
|---|---|---|
| Image Ridge | 固定 ResNet18 特征，岭回归预测表达 | C1 选择正则系数 1、10、100 或 1000 |
| MLP | 固定 512 维特征，256 维隐藏层，200 维输出 | AdamW，学习率 1e-3，批量 128，验证损失早停 |
| ST-Net | ImageNet DenseNet121，全参数微调，200 维回归头 | C1 PCC 选择第 10 轮及四旋转平均 |
| BLEEP | 固定 ResNet18 特征，双投影头对比学习，检索训练表达 | AdamW，学习率 1e-3，批量 128；C1 选择轮次和邻居数 |
| ResSAT | 图像、Fourier 坐标编码、FiLM 和 spot 注意力；预测 PCA50 后反投影 | 最多 100 轮，学习率 5e-4，批量 16，早停耐心值 10 |
| GenAR | 固定 ResNet18 特征和坐标，按六级基因分组生成计数 token | 完成 40 轮，批量 16，学习率 1e-4；训练损失保存权重，C1 选择末级 top-8 期望解码 |
| Stem | 固定 ResNet18 条件特征，12 层 DiT，隐藏维 384，6 个注意力头 | AdamW，学习率 1e-4，批量 32；验证损失保存权重，DDIM100 采样三次取均值 |

除 GenAR 的原始计数目标和 ResSAT 的 PCA 目标外，上述回归与扩散适配使用全转录组归一化后的 log 表达。评价时将输出转换为非负丰度，再按 HEG200 总量归一化并取 `log1p`。ContextFusion 直接学习最终评价单位，见[模型说明](MODEL.md)。

## 关键设置

ResSAT 的 PCA 仅在训练切片拟合；Fourier 特征数为 128，尺度参数为 1，Dropout 为 0.3。作者示例中的 float32、0–255 图块在送入 `ToPILImage` 前转为 uint8。其注意力在批内样本间计算；本地批量大小检查未发现明显指标变化。

GenAR 的层级为 1、4、8、40、100、200 个基因组，计数 token 上限为 2000。末级采用 top-8 token 的期望值，输出可为小数；中间层采用 top-1 解码。权重依据训练损失保存，解码方式依据 C1 选择。

Stem 使用固定验证噪声和时间步，EMA 衰减为 0.99。在 C1 的预定 256 个 spot 上比较参数和采样截断方式，选中当前参数与训练范围截断；第 60 轮权重用于推理。

各方法的编码器、训练目标、保存准则和计算预算存在差异，表中结果属于统一测试任务上的适配比较。原论文代码与参考提交见 [THIRD_PARTY.md](../THIRD_PARTY.md)。

## 复现记录

[baseline_20260913.csv](../benchmarks/liver/baseline_20260913.csv)保存人肝对照结果；高表达基因实验由 `scripts/34_*`–`43_*` 和 `scripts/50_*`–`52_*` 完成。脚本入口见[索引](../scripts/README.md)。

早期实验按方差选基因并排除核糖体、线粒体基因，该方案已被当前 HEG200 替代。相关问题与修正见 [PCC 诊断](05_PCC_DIAGNOSIS.md)。

ResSAT 鼠脑实验单独验证作者协议。另在 HEST-IDC 的四折、固定 50 基因设置下，ResNet50 layer3 特征配合 StandardScaler、PCA-256 和无截距 Ridge，平均 PCC 为 0.473872，公开参考为 0.4739。该结果用于核对特征与评价流程，不纳入人肝排名。
