# 多尺度模型与跨切片诊断

本页记录 2026-09-13 的 ContextFusion 实验。数据、HEG200/50 和指标沿用[固定基准](BENCHMARK.md)。后续六模型结果见[集成说明](ENSEMBLE.md)。

## 模型与训练

三个视野分别为 224、896、1792 原图像素，约对应 58、231、461 微米。图块缩放后共享 ResNet18，拼接特征经 LayerNorm 和 256 维隐藏层输出 200 个基因。标签按训练集统计量标准化，损失为 MSE 加 0.2 倍相关性损失。

ImageNet 初始化和全随机初始化先固定 seed 42 比较；预训练模型另运行 seed 17、83。每次最多 60 轮，C1 连续 12 轮无改善则停止。预训练编码器学习率为 3e-5，随机初始化编码器为 3e-4，预测头均为 3e-4。

单视野对照将同一张 224 像素图块重复三次，保持参数量和训练流程。三个预训练种子的等权平均由 C1 选出，作为基础组集成。

## 训练目标与计数条件

将 Ridge 的训练目标改为最终评价所用的面板相对表达后，单视野 D1 HEG200 PCC 从 0.0937 增至 0.0982，三视野从 0.1018 增至 0.1192。两种目标使用相同搜索预算，各自按 C1 选择配置。

每个 spot 的全转录组 UMI 总计数中位数为 A1 8134、B1 6537、C1 12423、D1 6010。固定 C1 预测，将计数按 0.48378 的保留概率二项降采样，重复 30 次：

| 模型 | 原 C1 HEG200/HEG50 | 降采样后均值 |
|---|---:|---:|
| 三尺度，ImageNet 初始化 | 0.3485 / 0.4854 | 0.3033 / 0.4447 |
| 三尺度，全随机初始化 | 0.3038 / 0.4385 | 0.2690 / 0.4045 |

计数减少导致 PCC 下降，支持计数条件对验证与测试差距有所贡献。该实验未分离生物 RNA 含量、捕获效率和测序过程的影响。

## 训练与跨切片表现

| 模型 | 训练 HEG200/HEG50 | C1 HEG200/HEG50 | D1 HEG200/HEG50 |
|---|---:|---:|---:|
| ImageNet 初始化 | 0.4308 / 0.6082 | 0.3485 / 0.4854 | 0.2176 / 0.3019 |
| 全随机初始化 | 0.3503 / 0.5102 | 0.3038 / 0.4385 | 0.2302 / 0.3278 |

模型能够拟合训练表达，跨切片性能仍有下降。三个预训练种子的 D1 PCC 均值及样本标准差为 HEG200 0.2146±0.0059、HEG50 0.2977±0.0037。

基础组三模型平均相对 ST-Net 的空间块 bootstrap 增益区间为 HEG200 [0.0552, 0.1057]、HEG50 [0.0662, 0.1545]。这些统计来自同一供体和同一测试切片。

## 补充诊断

C1 的逐基因 PCC 与 Moran's I 的 Spearman 相关为 0.724，与平均计数的相关为 0.647。用 C1 实测邻居表达进行标签侧诊断，HEG200/50 PCC 为 0.2602/0.4176；将计数随机拆为两个半深度样本，20 次平均相关为 0.2719/0.4655。两项诊断使用表达数据，不能作为仅输入图像的预测结果或性能上限。

仅用 H&E 配准连续切片，再迁移 A1/B1 参考表达，D1 PCC 为 0.1164/0.2061。该对照依赖同供体参考切片，单独保存结果。
