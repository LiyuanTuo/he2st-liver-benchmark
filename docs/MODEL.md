# ContextFusion 模型

每个 spot 裁取 224、896、1792 原图像素的正方形视野，统一缩放为 224×224。三幅图共享一个 CNN 编码器，特征拼接后经 LayerNorm、两层 MLP，输出固定 200 基因的表达。

```text
H&E + spot 坐标
    → 三尺度图像块
    → 共享 ResNet18 / EfficientNet-B0
    → 特征拼接 → MLP → 200 基因 log 表达
```

本批配置使用 ImageNet 初始化，但编码器和预测头均在 A1+B1 端到端训练。全随机初始化的旧版对照仍保留在历史结果中。输入坐标只用于裁图；模型不读取测试表达或用测试 RNA 构图。

训练标签使用训练集均值与标准差逐基因标准化；损失是 MSE 加 0.2 倍批内基因相关性损失。优化器为 AdamW，训练使用 warmup、余弦学习率衰减、梯度裁剪与颜色/旋转/翻转增强。EMA 是参数移动平均，在验证集比较原权重与 EMA 权重；再比较单次与四旋转推理。

`resnet18_spatial` 额外将**训练标签**与同一训练切片最近 6 个其他 spots 的均值按 0.8/0.2 混合。它检验局部平滑监督是否帮助泛化；验证和测试真值始终不变。平滑也可能抹去真实差异，必须报告对照结果。

代码职责：`data.py` 负责对齐和标签，`models.py` 负责网络，`engine.py` 负责训练/推理，`metrics.py` 负责指标，`cli.py` 负责命令行。实验组合单独放在 `experiments/`，避免将一次性实验写进模型定义。
