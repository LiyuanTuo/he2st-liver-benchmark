# 任务入门：从 H&E 到空间基因表达

## 1. 先认识两种数据

### H&E 图像

H&E 是病理学最常见的染色之一：苏木精通常让细胞核呈蓝紫色，伊红让细胞质、胶原和细胞外基质呈粉红色。整张切片（whole-slide image, WSI）尺寸可以达到数万像素，模型不会一次读完整分辨率，而是按空间测量点裁图像块。

H&E 告诉我们“组织长什么样”：细胞密度、核形态、腺体、纤维化、坏死和免疫浸润等；它本身没有直接测量每个 RNA 分子。

### 空间转录组数据

以 10x Visium 为例，玻片上有规则排列的捕获 spot。每个 spot 同时具有：

1. barcode：该测量点的唯一标识；
2. 空间坐标：在 H&E 图像中的像素位置；
3. 表达向量：该位置各基因的计数或归一化表达值。

因此核心数据不是普通 RGB 图，而是矩阵：

```text
                 ALB   GLUL   KRT19  PTPRC  ...
spot_0001        12      0       0      1  ...
spot_0002         8      3       0      0  ...
spot_0003         0      7       2      4  ...
...
```

选择矩阵中的一列（例如 `GLUL`），再把数值按照 spot 坐标画回 H&E，就得到一张基因空间表达图。不同基因会产生不同热图。

## 2. 模型究竟学什么

对第 `i` 个 spot：

```text
H&E 图像块 x_i + 坐标 s_i + 可选邻域 context_i
                         ↓ 模型 f(·)
预测表达向量 y_hat_i = [gene_1, gene_2, ..., gene_G]
```

训练时把 `y_hat_i` 与实验真值 `y_i` 比较。不同论文的主要差异是：

- ST-Net：把每个 spot 当作独立回归样本；
- BLEEP：把图像和表达投影到同一空间，用相似训练样本做插补；
- ResSAT：让不同 spot 通过注意力交换信息，并用空间坐标调制图像特征；
- Stem：学习条件表达分布，通过扩散过程生成表达；
- GenAR：把原始整数计数作为离散 token，按层次基因组从粗到细生成。

## 3. “生成”不等于凭空创造可靠测量

这里的“生成空间转录组”容易造成三种误解：

1. **不是 H&E 染色中直接读出了 RNA。** 它是从训练样本学习统计关联。
2. **不是所有基因都能由形态预测。** 没有明显形态表型的通路、瞬时状态和低表达基因可能很难预测。
3. **预测图不能自动当作新生物学发现。** 高相关不保证差异表达、通路富集或空间域分析仍然可靠，必须做下游验证和不确定性分析。

所以本项目把输出称为“预测/计算生成的表达”，并始终保留实测 ST 作为测试真值。

## 4. 一张真实切片在项目中的文件关系

```text
H&E WSI (.tif/.jpg)
  └─根据 tissue_positions 中的像素坐标裁 patch

tissue_positions_list.csv
  ├─barcode
  ├─是否在组织内
  ├─阵列行列
  └─H&E 像素行列

matrix.mtx + barcodes.tsv + features.tsv
  └─按 barcode 与坐标表对齐，得到 spot × gene 真值

统一缓存
  ├─patch 或图像特征
  ├─坐标
  ├─原始计数
  ├─归一化表达
  └─切片/基因/预处理元数据
```

最危险的数据错误是 barcode 或 spot 顺序错位：图像块仍然“看起来正常”，但标签属于另一个位置。预处理必须逐条按 barcode 对齐并做哈希/形状检查。

## 5. 怎样判断效果好不好

### 预测数值

- `PCC-all`：逐基因计算跨 spot 的 Pearson 相关，再对预先固定的全部基因取平均。
- `Spearman-all`：更关注排序，对异常值较稳健。
- `MAE / RMSE`：衡量绝对误差，必须说明是在原始计数还是归一化尺度上。
- `spot cosine`：逐 spot 比较整条基因向量的方向。

### 分布和空间结构

- 零值比例误差：生成模型是否正确恢复稀疏性；
- 均值—方差关系：是否把不同 spot 过度平滑成相似表达；
- 空间自相关/Moran's I：预测是否保留空间组织结构；
- 基因热图：真值与预测是否在正确解剖区域共同升高。

### 评测陷阱

- 在测试结果中挑“相关性最高的 top-k 基因”只能说明最好预测的部分，不能代表整个基因面板。
- 随机拆分同一张切片的 spot 会使相邻区域同时出现在训练和测试中，通常虚高结果。
- 在全数据（含测试切片）上选择 HVG、做批次校正或标准化，会泄漏测试分布。
- 不同方法若用不同基因数、表达尺度、图像编码器或切片划分，PCC 不能直接横向比较。
