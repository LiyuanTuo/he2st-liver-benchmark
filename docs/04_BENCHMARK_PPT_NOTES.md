## 2. 必须说明的旧表问题

检查 `scripts/02_prepare_expression.py` 和 `scripts/15_make_comparison.py` 发现：

- Ridge、MLP、BLEEP、ResSAT、Stem 的旧评测标签，是先按**全部基因总计数**归一化，再取 200 列。
- GenAR 的旧汇总，却按**所选 200 基因总计数**归一化真值和预测。
- 虽然公式都写成 `log1p(10000 × 表达 / 总量)`，分母不同，单位并不一致。

因此，旧表中 GenAR 与其他方法的跨方法直接比较不成立。其余同口径模型之间的旧比较不因此全部作废。
本轮不是“模型训练得更好”，也不是用新数字去替换原论文结果。

### 新汇报采用新增的统一后处理比较

所有方法都比较 **200 基因面板内部的相对表达**：

```text
GenAR：已保存的原始预测计数 ─────────────────────┐
其他方法：已保存的 log 表达 → expm1 → 负值截为 0 ├─→ 每行 200 列合计缩放至 10000 → log1p
实测真值：统一数组中的 200 列原始计数 ────────────┘
```

预测和真值分别使用**自身**行和；没有用 D1 实测总计数帮模型转换预测。
其他方法的 `expm1` 结果是相对丰度，不是恢复出的绝对原始计数；整行比例因子在面板内重新归一化时消去。
面板全零位置保留为零，不删除测试位置。源预测和模型权重保持不变。

这是一项明确的**评价口径变更**：评价面板内的组成/空间变化，不再评价面板相对于整个转录组的总量变化。
它不等价于原训练损失，也不等价于各论文的原协议，更不能宣称全转录组或绝对 RNA 计数已生成成功。
原来的全基因归一化评价仍可作为非 GenAR 模型的另一个独立口径保留，不能混表。

### 新汇报结果

训练 A1+B1（4,727 spots），验证 C1（2,277），测试 D1（2,265），固定 200 基因。

| 本地实现 | 平均 PCC ↑ | MAE ↓ |
|---|---:|---:|
| ResSAT 适配 | 0.087075 | 1.288180 |
| BLEEP 适配 | 0.053442 | 1.327354 |
| ST-Net 风格 MLP，不是原版 ST-Net | 0.050988 | 1.307064 |
| Image Ridge | 0.042034 | 1.319653 |
| GenAR 适配 | 0.005147 | 1.340468 |
| Stem 适配（三次生成的均值） | 0.003002 | 2.086025 |
| 训练集逐基因均值，不看测试图像 | 无定义 | 1.291598 |

PCC 逐基因跨 2,265 个位置计算，再对固定 200 个基因平均；六种模型这 200 个 PCC 均有定义。
常数均值基线的 PCC 无定义，不伪装成有预测能力的正相关。
ResSAT 的 MAE 仅比均值参照低约 0.0034，不能只看误差来宣称空间预测成功。
Stem 保存的均值预测约 **34.05% 为负值**，后处理统一截为零；这是当前适配仍需诊断的迹象。

## 3. 预测图怎样保证可比较

- GLUL 与 IGKC 沿用此前已经展示过的基因，不根据本轮分数挑最优基因。
- 每页有实测值和全部六种方法，没有只保留表现好的方法。
- 同页用相同的 spot 坐标、朝向、图像范围、色图和数值范围。
- 颜色下限为 0，上限取该基因真值与六法预测的共同最大值；无百分位截断。
- 不平滑、不插值、不单独拉伸不同方法的颜色，也不裁拼旧预测图。
- 不同基因的数值范围可以不同；不能跨两个基因页直接比较颜色亮度。
- “颜色变化多”不等于恢复空间结构；应看是否出现在正确位置，并结合全基因指标。

## 5. 比较边界与复核

共享切片、基因与评测单位不等于所有训练条件完全公平：除 ResSAT 微调 ResNet50 外，其余五种图像方法使用冻结 ResNet18 特征，训练预算也不同。
GSE240429 又是 BLEEP 原论文使用的数据，不能视为对各论文完全独立的验证队列。
这里只有同一人肝样本的切片留出，不支持跨患者泛化结论。生成式适配的负结果不能推翻原论文。

已验证：六个预测的基因、标签行序、形状与有限性；五个带坐标预测的坐标逐元素一致。
计数直接面板归一化，与原 log 标签 `expm1` 后面板归一化的最大差为 `2.34e-7`。
比例缩放不变性、全零处理、PCC 自相关为 1、常数 PCC 无定义均通过检查。
