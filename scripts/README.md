# 方法适配与早期实验

编号脚本用于方法适配和早期实验；常规训练、预测使用 `run.py`，见[运行指南](../docs/QUICKSTART.md)。

| 实验 | 脚本 |
|---|---|
| 下载与原始数据检查 | `00_*`、`02_*`、`05_*` |
| 训练集高表达基因选择 | `34_build_heg_panel.py` |
| 七种基线的 HEG 实验 | `35_*`–`43_*`、`29_train_stnet_densenet.py` |
| ResSAT 复现与指标核验 | `44_*`、`50_*`、`50b_*`、`50c_*`、`51_*`、`52_*` |
| 多尺度模型与诊断 | `57_*`–`65_*`、`67_*`、`69_*`、`70_*` |

`02_*` 为早期方差选基因方案，当前 HEG200 由 `34_*` 定义。

部分脚本依赖 `third_party/` 中的作者代码及本地结果缓存。参考版本见 [THIRD_PARTY.md](../THIRD_PARTY.md)，参数和结果见[方法适配](../docs/02_METHODS_AND_PROTOCOL.md)及[多尺度实验](../docs/06_LIVER_CONTEXT_IMPROVEMENT.md)。
